# canonmark

> Tell your AI agents which doc to trust.

`markdownlint` checks formatting, `Vale` checks prose, `lychee` checks links —
nothing checks whether a doc *still counts*. canonmark makes document authority
a machine-checkable contract in your `docs/`: which doc is current, which is
superseded, who wins a conflict — and breaks the build when your docs lie about it.

**Status: early development (P0).** See [docs/roadmap.md](docs/roadmap.md) for the
plan and [docs/design/vision.md](docs/design/vision.md) for the why. This README is
a placeholder to be expanded in P1.
